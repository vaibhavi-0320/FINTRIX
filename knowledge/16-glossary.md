# Glossary

- **Advance / price:** what the investor pays the seller now.
- **Annualised yield:** return expressed as a yearly rate (simple interest).
- **Basis point (bps):** one hundredth of a percent; 100 bps = 1%.
- **Contract id:** Soroban contract address, starting with C.
- **Document fingerprint / hash:** SHA-256 hash of the uploaded invoice file, stored on-chain.
- **Escrow:** funds held by a neutral party (here, the smart contract) until a condition is met.
- **Extraction:** turning an invoice document into structured fields.
- **Freighter:** Stellar browser-extension wallet.
- **Albedo:** Stellar web wallet that signs in a popup, no install needed.
- **Trust Score / Risk Level:** the app's display of the modelled late-payment probability; lower is safer.
- **Friendbot:** testnet faucet that funds new accounts.
- **Horizon:** Stellar API for accounts and history.
- **Ledger:** a block of Stellar transactions, closed about every 5 seconds.
- **Network passphrase:** string identifying a Stellar network; signatures are bound to it.
- **RAG:** retrieval-augmented generation – the assistant retrieves relevant documentation before answering.
- **Repayment:** what the seller pays back (the invoice total).
- **SAC:** Stellar Asset Contract, the token interface for Stellar assets in Soroban.
- **SEP-53:** Stellar standard for signing arbitrary messages with an account key.
- **Simulation:** dry run of a Soroban call to compute fees and detect errors before signing.
- **Soroban:** Stellar's smart-contract platform.
- **Stroop:** smallest XLM unit, 0.0000001 XLM.
- **XLM (lumens):** Stellar's native asset.
